Me gusta construir productos completos: frontend con intención visual, backend con APIs claras, datos bien modelados y automatizaciones que ahorran tiempo real. Uso IA como copiloto técnico —para acelerar exploración, pruebas y refactor— sin dejar de revisar, ejecutar y entender lo que termino integrando.
